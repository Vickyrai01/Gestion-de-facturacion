# Sistema de Gestión de Facturación

Aplicación de referencia para una capacitación de migración desde .NET Framework a .NET moderno. Esta rama acumula el Módulo 1 y el Módulo 2: clientes, productos, facturas, EF6/SQL Server, consultas SOAP WCF, Windows Service y Forms Authentication, conservando ASP.NET MVC 5 sobre .NET Framework 4.8.

Abrir `legacyGestionDeFacturacion.web/legacyGestionDeFacturacion.web.slnx` en Visual Studio para Windows, restaurar NuGet, compilar y ejecutar con IIS Express.

La [guía del Módulo 2](docs/modulo-2/README.md) explica preparación de la base, cuentas locales, ejecución y material de las clases 3, 4 y 5. La [guía del Módulo 1](docs/modulo-1/README.md) conserva el contexto histórico de su rama y las clases 1 y 2. El proyecto moderno se construirá por separado durante el curso.
