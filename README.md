# Sistema de Gestión de Facturación

Aplicación de referencia para una capacitación de migración desde .NET Framework a .NET moderno. El Módulo 1 implementa administración de clientes con ASP.NET MVC 5 sobre .NET Framework 4.8.

Abrir `legacyGestionDeFacturacion.web/legacyGestionDeFacturacion.web.slnx` en Visual Studio para Windows, restaurar NuGet, compilar y ejecutar con IIS Express.

La [guía del Módulo 1](docs/modulo-1/README.md) incluye requisitos, ejecución, estructura, alcance y enlaces al material de las clases 1 y 2. El proyecto moderno se construirá por separado durante el curso.
